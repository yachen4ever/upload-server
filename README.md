# upload-server

最简单的单文件 HTTP 文件上传服务器，**零依赖**（仅 Python 标准库，3.9+ 可用）。

浏览器打开即用：选择文件 → 上传 → 保存到服务器指定目录。

## 用法

```bash
python3 upload_server.py                 # 默认保存到 /srv，监听 0.0.0.0:1983
python3 upload_server.py /data/up 8080   # 自定义保存目录和端口
```

浏览器打开 `http://<服务器IP>:1983`，选文件上传即可。

## 特性

- 单文件、零依赖，只用 `http.server` 标准库，无 pip 要求
- 流式写盘：大文件上传不占内存
- 中文文件名正常保存（UTF-8，兼容浏览器原始编码与 RFC 5987 两种格式）
- 同名文件不覆盖，自动加时间戳后缀
- 上传中断自动删除半截文件
- 兼容 Python 3.9 ~ 3.14+（未使用已被移除的 `cgi` 模块）

## 注意

- **无任何鉴权**，任何能访问该端口的人都可以传文件，只放可信内网使用
- `/srv` 等系统目录需要权限：`sudo python3 upload_server.py` 或先 `chown` 给当前用户
